# Common Errors

- Placeholder output only:
  - Cause: command implementation is pending.
  - Action: report status clearly and do not claim Alembic was configured.

- Command not found:
  - Cause: CLI not installed or environment not activated.
  - Action: install/activate project CLI and rerun.
